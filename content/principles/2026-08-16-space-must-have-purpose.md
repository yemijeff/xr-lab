# Principle 01: Don't put a 2D interface into 3D without a reason

A common failure mode in spatial design is wrapping traditional 2D dashboard rectangles around the user like an IMAX theater. True spatial product design uses volume, spatial audio, and world anchoring to communicate information that flat screens cannot convey.
